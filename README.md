# Обработчик анкет

Программа читает файл с анкетами, проверяет данные, печатает таблицу принятых анкет и список брака, а результаты сохраняет в файлы.

## Запуск

```
python main.py
```

## Формат входного файла

Файл `anketa.txt` лежит рядом с `main.py`. Одна строка - одна анкета, четыре поля через точку с запятой:

```
ФИО ; почта ; телефон ; группа
```

Пустые строки пропускаются. Пример файла - `anketa.txt` в репозитории.

## Что делает программа

- приводит ФИО, почту, телефон и группу к единому виду;
- отбраковывает анкеты с ошибками и называет причину;
- выводит таблицу (телефон скрыт маской), список брака и статистику по группам;
- сохраняет принятые анкеты в `ok.txt`, бракованные - в `errors.txt`.

## Структура проекта

```
main.py          точка входа: порядок действий
validators.py    проверки ФИО, почты, телефона, группы
report.py        таблица, список брака, статистика
storage.py       чтение входного файла, запись результатов
data/anketa.txt  пример входных данных
```
